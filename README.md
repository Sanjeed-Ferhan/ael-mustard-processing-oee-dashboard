# AEL (Mustard Oil) — Processing

Single-file HTML dashboard for **AEL (Mustard Oil) — Processing line** (Mustard Seed).

## Features
- **Toggle:** Last completed day and Month-to-date
- OEE KPIs (A/P/Q/Overall) vs targets **A90 / P86 / Q97 / OEE75**, with overall **Out x/y MT**
- Where time is going; OEE by unit; Find-the-bottleneck
- Top downtime + downtime by category (min) — unplanned only
- Opportunity Loss = NPT min ÷ cycle time (min/MT) → lost output (MT)
- Production & OEE trend; Shift Action Board; Shift OEE; Gemba walk

## Data source
`Processing Line` (gid=0) and `Breakdown` (gid=482789258) tabs of the AEL (Mustard Oil) OEE sheet (Breakdown filtered to the Processing section). Live on open.
